# 拼好图 · pinhaotu

> **三张图当一张图修，拼出一张好图片。**

## 先说个熟悉的场景

凌晨一点，你打开像素蛋糕，硬盘里躺着 12 张待修的人像。

按老办法，你得修 12 次——额度像纸巾一样抽走。

拼好图的思路有点"狡猾"：**先把 12 张拼成 5 张大画布，只修 5 次，再一刀一刀切回 12 张。**
额度省了一多半，每张照片拿回来还是原始像素。

听起来像作弊，其实只是把"排版"从修图软件里拿出来单独做了。
修图仍然是像素蛋糕的活，拼好图只负责让你少付几次钱。

> 本仓库是 **Windows 版**：纯 Python + Pillow，双击 `启动.bat` 就能跑。
> 不用装 Electron，不用编译 native 模块，也不用先学会 Node.js。

---

## 它到底干什么

- **拼**：把 N 张照片按最省额度的方式装进尽量少的画布，每边不超过像素蛋糕的导入上限。
- **护**：每张图四周铺一圈自身镜像当"保护带"，精修时的液化不会跨缝污染邻居。
- **切**：记住每张图的精确矩形，精修完原样切回来——**逐像素偏差 = 0**。
- **记账**：每批导出都会记下省了多少次、折合多少钱（默认按 299 元 / 800 张折算，约 0.37 元一张）。

它不修图、不调色、不美颜。这些交给像素蛋糕，它只做前处理和后处理。

## 五步走完：拼 → 修 → 切

```
① 拖入照片  →  顶部选相机机型（或让它自动识别）
② 点「自动排版」     → 算出最少画布数 + 显示「省几次」
③ 点「全部导出」     → TILE_xxx_c01.tif + .manifest.json
④ .tif 导入像素蛋糕 → 只做调色 → 导出 TIFF（别改文件名）
⑤ 选回导出的 tif    → 点「③ 一键切回原图」
```

第 ④ 步是唯一需要你"守规矩"的地方，规则见下面红牌区。

## 排版的三条铁律

这一节是整个工具的核心。看懂这三条，你就比 90% 的使用者更懂它。

### 铁律一：人脸必须朝上

**默认零旋转。** 竖图竖着排、横图横着排，原始朝向一个字都不改。

因为这是修人像——一张侧躺的脸进像素蛋糕，人脸识别可能直接罢工，修出来是什么样全凭运气。

### 铁律二：密度靠"横竖混排"，不靠转图

同一台机身的照片，窄边相同、长边相同，竖图和横图的占位刚好互补。
于是会出现这种反直觉的结果：

| A7M4（7008×4672 / 4672×7008），上限 12000、保护带 12 | 单画布张数 |
|---|---|
| 全横 | 2 |
| 全竖 | 2 |
| **横竖混排** | **3** |

3 张怎么塞进去的：竖图立成左窄列（宽 4696），横图叠成右宽列（宽 7032，两张高 9392），
总宽 4696 + 7032 = 11728 ≤ 12000。**一张都没转，人脸全正。**

> 不同机身结论不同：A7R（7952×5304）横竖互拼都超 12000，单画布只能 2 张。
> 顶部会按当前机型实时显示竖 / 横 / 混排各能放几张。

### 铁律三：保护带不要设 0

每张图四周（含四个角）铺 12px 自身镜像。拼缝处像素连续，
精修时的液化位移场走到边缘，取到的是**自己**而不是隔壁老王。

设 0 等于让所有照片的液化互相污染：你推一下 A 的腰，B 的胳膊跟着动。

### 附：那个"允许旋转 90°"开关

默认关着。关着就对了。

开了之后排版器会把**个别**照片转 90° 塞进窄列换密度——代价是那几张人脸侧躺。
除非你修的是风景、静物、建筑，否则别碰它。

`row` / `col` 版式**永远不旋转**，哪怕开关是开的——一字排开的照片必须张张人脸朝上。

## 红牌区：碰了这些，切回就废

| | |
|---|---|
| ✅ **可以做** | 曝光、对比、高光阴影、白平衡、色温、曲线、HSL、分离色调、纯色彩类预设、滤镜 |
| ❌ **绝对不要** | 液化、脸型、瘦身、身材、AI 换背景、AI 天空、AI 消除、AI 扩图、换装、证件照排版 |
| ❌ **不要裁剪** | 改变宽高比 → 切回直接拒绝 |
| ❌ **不要开排版印刷** | 同上 |
| ❌ **不要改文件名** | 靠文件名配对 manifest |
| ✅ **导出选 TIFF** | 唯一能无损往返的格式 |

**为什么禁液化 / AI**：几何变形 + 生成式重绘，拆开后像素不可逆，人脸 / 肤色还会被整画布统计污染。

**为什么允许调色**：曝光 / 白平衡 / 曲线是**逐像素静态映射**，拆回来各自带走，跨缝不污染。

一句话：**能让每个像素只依赖它自己的，都行；会让像素互相商量的，都不行。**

## 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| 画布单边上限 | 12000 | **13000 是导入硬闸门**：超过直接弹「图片尺寸过大」被拒，连静默降采样都不会发生 |
| 保护带 (px) | 12 | 每张图四边四角铺自身镜像。**不要设 0** |
| 间隙 (px) | 0 | 纯视觉分隔，不影响精度 |
| 允许旋转 90° | **关** | 修人像请勿开 |
| 版式 | grid | grid = 自动装箱（朝向感知）；row / col = 单行 / 单列 |

> **三级上限别记混**：`13000` 导入硬闸门 → `12000` 推荐值（默认）→ `16384` GPU 纹理上限。
> 16384 超了只是悄悄降分辨率，不是导入门——**拿它当上限用，整批白拼**。
>
> 另外两条硬限制：单边 `<100px` 或文件 `>1GB` 同样拒收。
> 画布过小会直接报错；导出超过 1GB 会在日志里橙色告警。

## 导出后你会看到

```
拼好图导出/
  TILE_a1b2c3d4e5_c01.tif              ← LZW 无损画布
  TILE_a1b2c3d4e5_c01.manifest.json    ← 切分唯一依据（绝对矩形 + 源 sha256 + 内嵌 EXIF）
  切回原图/
    shot1.jpg
    shot2.jpg
```

`.manifest.json` 里内嵌了每张图的 EXIF（`exifB64`），所以**原图归档或移走后照样能写回拍摄信息**。

别删它。它既是切分的唯一依据，也是这笔"额度账"的凭证。

## 凭什么敢说"一个像素都不差"

因为它真的被逐像素测过，不是嘴上说说。

```bash
python tiler_core.py            # 排版 / 合成 / 切回 自检，逐像素偏差必须 = 0
python tests/e2e_test.py        # 全链路（含模拟精修、缩放、裁剪拒绝）
python tests/_ui_shots.py       # UI 冒烟 + 截图（存到 tests/_shots/）
```

| 项目 | 结果 |
|---|---|
| 原样切回 | 全局最大像素偏差 **= 0** |
| 调色后切回 | 结构相关 **0.99984**（几何零漂移） |
| 导出被缩放 75% | 按比例映射 + 告警 |
| 宽高比被改（裁剪） | **直接拒绝** |
| A7M4 5 张混排（3 横 2 竖，不旋转） | 2 张画布，填充 89.2% / 79.4% |
| A7M4 12 张混排（6 横 6 竖，不旋转） | 5 张画布 = 数学最优 |
| A7M4 单画布容量（12000 / 保护带 12） | 全横 2 / 全竖 2 / **混排 3** |
| EXIF 往返 | JPEG 走 APP1 整段搬运；TIFF / PNG 走 Pillow 通道 |

切回时如果检测到尺寸或宽高比对不上，它会**拒绝切分**而不是糊弄你——
宁可让你重来一次，也不给你一堆悄悄重采样过的"原图"。

## 诚实清单：它做不到的事

1. **画布上的脸是整张图一起做统计的**。建议同一场拍摄、同一光线；
   软件会把每张画布的**拍摄时间跨度**显示在副标题，超阈值变橙告警，
   照片列表也带「拍摄」列，可一键按时间排序。
2. 保护带约占 2% 面积（画布边缘那圈镜像条）。
3. 一张 10000×10000 的 LZW TIFF 约 30–80 MB。
4. **HEIC / RAW 不支持**，先转 JPG / TIFF。
5. 合成是串行贴图，峰值内存 ≈ 画布 + 一张源图。
6. **切回格式选 TIFF 时 EXIF 会不全**：Pillow 的 TIFF 编码器写不了 ExifIFD 子目录，
   光圈 / 快门 / ISO / 镜头带不出（方向 / 机型 / 拍摄时间可以），
   `warnings` 会明确告诉你。要完整 EXIF 请选 **JPEG 或 PNG**。
7. **row / col 混排时会留白**：尺寸不同的照片，较窄/较矮的一侧填背景色。
   这是为了切回原像素——**绝不缩放**。同机型同朝向不会有留白。

## 名字与结构

"拼好图"三个字挺好用：既是"把图拼好"，也是"拼出好图"。

```
拼好图/
├── README.md                         用户手册（本文件）
├── 启动.bat                          双击启动
├── tiler_core.py                     引擎（排版 / 合成 / 切分 / EXIF / manifest / 账本）
├── tiler_ui.py                       界面组件层（设计令牌、Card、StepButton、Badge…）
├── tiler_gui.py                      Tkinter 主程序
├── 像素蛋糕-图片与画布限制.md          逆向取证：导入尺寸 / 文件体积的硬限制
├── docs/
│   ├── 开发文档.md                    内部设计说明
│   └── EXIF全链路与同场同光优化.md     设计决策存档
└── tests/
    ├── e2e_test.py                   端到端测试
    └── _ui_shots.py                  UI 冒烟 + 截图

运行时自动生成（已在 .gitignore 中）：
  ledger.json                           省额度账本
  tests/_shots/                         UI 截图产物
```
