# 像素拼图 · Windows 版 v2

把多张照片 **1:1 无损**拼成一张像素蛋糕能处理的画布，精修后按记录精确切回原图。

> 思路参考 [pixcake-tiler](https://github.com/wjunfei88-maker/pixcake-tiler)（macOS 版），
> 本目录是 **Windows 实现**：纯 Python + Pillow，无 Electron / 无 native 构建。

---

## 快速开始

**双击 `启动.bat`**（首次会自动装 Pillow）。

---

## 使用流程

```
① 拖入照片  →  顶部选相机机型（或自动识别）
② 点「自动排版」     → 自动算最少画布数 + 显示「省几次」
③ 点「全部导出」     → TILE_xxx_c01.tif + .manifest.json
④ .tif 导入像素蛋糕 → 只做调色 → 导出 TIFF（别改文件名）
⑤ 选回导出的 tif    → 点「③ 一键切回原图」
```

**排版默认不动朝向**：竖屏照片竖着排、横屏照片横着排，人脸始终朝上，
靠「竖列 + 横列混排」省图（A7M4 能把 3 张拼进一张画布且一张都没转）。
「允许旋转 90°」默认关闭 —— 修人像不要开，开了那几张脸会侧躺。

## v2 相对 v1 的改进

| 方向 | 改进 |
|---|---|
| **像素蛋糕适配** | 三级上限：`导入硬闸门 13000` / `推荐值 12000` / `GPU 纹理 16384`（超过 13000 会弹窗警告并引导回落）。保护带默认 12px，四个边角都铺自身镜像 |
| **相机尺寸适配** | 内置 28 款主流机身真实尺寸（A7M4 / R5 / Z8 / GFX100 / X2D…），**自动识别**；顶部实时显示「这台机器单边 12000 下单画布竖/横/混排各能放几张」 |
| **朝向优先（修人像关键）** | **默认零旋转**：竖屏照片竖着排、横屏照片横着排，人脸始终朝上，像素蛋糕的人脸识别不会失效。密度靠「竖列 + 横列混排」拿（A7M4：1 竖列 + 1 横列 = 11728px ≤ 12000 → 同画布放 3 张，且一张都没转） |
| **排版质量** | 朝向感知列带 + 货架 + MaxRects × 8 排序键 × 24 随机起点 + 紧包围盒重压 + 多起点分组 + 画布合并 + 搬空重填 |
| **元数据** | 切回时把拍摄信息写回单张：厂商 / 机型 / 镜头 / 拍摄时间 / 光圈 / 快门 / ISO。**EXIF 内嵌进 manifest**，源图归档、改名、移走也能对上；同时摘掉旧缩略图、`Orientation` 归一到 1（竖拍不躺倒） |
| **同场同光把关** | 照片列表带「拍摄」列（`MM-DD HH:MM`，来自 EXIF），可一键**按拍摄时间排序**；每张画布的副标题显示画布内**拍摄时间跨度**，超出阈值变橙告警——一眼看出有没有混进别的场次 |
| **界面** | 照片列表带缩略图；画布可视化预览（虚线框标保护带）；**画布上可直接拖动照片微调**，松手检查重叠；真实进度条 |
| **账本** | 「省额度」页：已省 N 次 · ¥X，单张均价可改，按批次记录 |
| **版式** | grid（自动装箱）/ row（横排）/ col（竖排）。row/col **按原始像素放置、不缩放**，交叉轴居中、多出的部分留白；一排装不下会**自动拆成多张画布** |

## 关键规则（违反会毁图）

| | |
|---|---|
| ✅ **可以做** | 曝光、对比、高光阴影、白平衡、色温、曲线、HSL、分离色调、纯色彩类预设、滤镜 |
| ❌ **绝对不要** | 液化、脸型、瘦身、身材、AI 换背景、AI 天空、AI 消除、AI 扩图、换装、证件照排版 |
| ❌ **不要裁剪** | 改变宽高比 → 切回直接拒绝 |
| ❌ **不要开排版印刷** | 同上 |
| ❌ **不要改文件名** | 靠文件名配对 manifest |
| ✅ **导出选 TIFF** | 唯一能无损往返的格式 |

**为什么禁液化/AI**：几何变形 + 生成式重绘，拆开后像素不可逆，人脸/肤色也会被整画布统计污染。
**为什么允许调色**：曝光/白平衡/曲线是**逐像素静态映射**，拆回来各自带走，跨缝不污染。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 画布单边上限 | 12000 | **13000 是导入硬闸门**：超过直接弹「图片尺寸过大」被拒，连静默降采样都不会发生。12000 与官方素材链路一致，留 1000px 余量 |
| 保护带(px) | 12 | 每张图四边四角铺自身镜像。**不要设 0**——液化的位移场会跨缝拉扯 |
| 间隙(px) | 0 | 纯视觉分隔 |
| 允许旋转 90° | **关** | 关＝所有照片保持真实朝向（人脸朝上）。开了才让排版器按需把个别照片转 90° 塞进窄列换密度，代价是那几张**人脸侧躺、人脸识别可能失效**，修人像请勿开 |
| 版式 | grid | grid=自动装箱（朝向感知）；row/col=单行/单列。两者都按原像素放置（混排时留白，不缩图），超出单边上限自动拆画布 |

## 输出

```
像素拼图导出/
  TILE_a1b2c3d4e5_c01.tif              ← LZW 无损画布
  TILE_a1b2c3d4e5_c01.manifest.json    ← 切分唯一依据（绝对矩形 + 源 sha256 + 内嵌 EXIF）
  切回原图/
    shot1.jpg
    shot2.jpg
```
> `.manifest.json` 里内嵌了每张图的 EXIF（`exifB64`），所以**原图归档或移走后照样能写回拍摄信息**。
> 别删它，它同时是切分的唯一依据。

## 已验证

```
python tiler_core.py            # 排版/合成/切回 自检，逐像素偏差必须 = 0
python tests/e2e_test.py        # 全链路（含模拟精修、缩放、裁剪拒绝）
python tests/_ui_shots.py       # UI 冒烟 + 截图（存到 tests/_shots/）
```

实测结果：

- 原样切回：**全局最大像素偏差 = 0**
- 调色后切回：结构相关 = **0.99984**（几何零漂移）
- 导出被缩放 75%：按比例映射 + 告警
- 宽高比被改（裁剪）：**直接拒绝**
- A7M4 5 张混排（3 横 2 竖，**不旋转**）：2 张画布，填充 89.2% / 79.4%
- A7M4 12 张混排（6 横 6 竖，**不旋转**）：5 张画布 = 数学最优（详见开发文档 4.3）
- A7M4 单个画布容量（上限 12000 / 保护带 12）：全横 2 张 / 全竖 2 张 / **横竖混排 3 张**
- EXIF：JPEG 走 APP1 整段搬运，TIFF/PNG 源图走 Pillow 通道；
  摘缩略图、`Orientation=6 → 1`；EXIF 内嵌进 manifest，**原图移走也能写回**
- 端到端第 [8] 节：三种源图 × 三种输出格式的 EXIF 往返

## 已知边界

1. 画布上的脸是**整张图一起**做统计的，建议同一次拍摄、同一光线。
   软件会把每张画布的**拍摄时间跨度**显示出来（副标题），跨度超出阈值会变橙告警，
   一眼就能看出这张画布是否混了不同场次。照片列表也带「拍摄」列，可一键按时间排序。
2. 保护带会占约 2% 面积（画布边缘那圈镜像条）。
3. 一张 10000×10000 的 LZW TIFF 约 30–80MB。
4. HEIC / RAW 不支持，先转 JPG/TIFF。
5. 合成是串行贴图，峰值内存 ≈ 画布 + 一张源图。
6. **切回格式选 TIFF 时，EXIF 只能带出方向 / 机型 / 拍摄时间**：
   Pillow 的 TIFF 编码器写不了 ExifIFD 子目录，光圈 / 快门 / ISO / 镜头 带不出，
   切回报告的 `warnings` 里会明确告知。要完整 EXIF 请选 **JPEG 或 PNG** 输出。
7. **row / col 版式混排时会留白**：不同尺寸的照片混排时，较矮/较窄的照片
   两侧（或上下）会填背景色。这是为了保证切回是原像素——**绝不缩放**。
   同机型同朝向的照片尺寸一致，不会有留白，效果与「排齐」完全相同。
